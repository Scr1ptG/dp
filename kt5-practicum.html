Раздел 1 · Шаблон

Три вопроса — и код пишется сам

1. Что такое dp[i]?

Ответ для задачи размера i. Скажите это словами вслух.

2. Какая база?

Ячейки, которые известны сразу: dp[0], иногда dp[1].

3. Какой переход?

Как dp[i] собирается из уже посчитанных ячеек.

Если не можете ответить словами — код писать рано. Сначала проговорите три ответа.

// Скелет любой задачи ДП снизу вверх
int[] dp = new int[n + 1];   // +1: нужен индекс n
dp[0] = ...;                 // база
for (int i = 1; i <= n; i++) {
    dp[i] = ...;             // переход из dp[i-1], dp[i-2] ...
}
return dp[n];                // ответ

Задача: сколько способов подняться по лестнице. Что такое dp[i]?

Раздел 2 · Задача 1 · 2 балла

Задача 1: лестница

Условие

Лестница из n ступенек. За шаг можно подняться на 1 или 2 ступеньки. Сколько существует разных способов дойти до верха?

static int ways(int n)

Ответы для проверки

ways(1) → 1
ways(4) → 5
ways(10) → 89

Три вопроса:

  • dp[i] — число способов дойти до ступеньки i.
  • База: dp[0] = 1, dp[1] = 1.
  • Переход: dp[i] = dp[i−1] + dp[i−2].

Чему равно ways(6)? Прогони таблицу до шестой ячейки.

Раздел 2 · Задача 1 · разбор

Найди ошибку в чужом решении

static int ways(int n) {
    int[] dp = new int[n];
    dp[0] = 1;
    dp[1] = 1;
    for (int i = 2; i < n; i++) {
        dp[i] = dp[i - 1] + dp[i - 2];
    }
    return dp[n - 1];
}

Что здесь не так

  • Массив размера n, а нужен n + 1.
  • Цикл идёт до n − 1, значит ответ для n так и не посчитан.
  • Возврат dp[n - 1] — это ответ для лестницы на одну ступеньку короче.

Проверяйте себя одним тестом: ways(4) должно быть 5. Если вышло 3 — ошиблись на единицу.

Раздел 3 · Задача 2 · 3 балла

Задача 2: минимум монет

Условие

Даны номиналы монет и сумма. Монет каждого вида сколько угодно. Найти минимальное число монет.

static int minCoins(int[] coins, int sum)

Три вопроса

dp[s] — минимум монет на сумму s.
База: dp[0] = 0.
Переход: dp[s] = min(dp[s − c]) + 1.

Ответы для проверки

{1,3,4}, 6  → 2
{1,3,4}, 11 → 3
{2}, 3      → -1

Почему для монет {2} и суммы 3 ответ −1?

Чему равно dp[7] для монет 1, 3, 4?

Раздел 3 · Задача 2 · практика

Заполни пропуски в minCoins

static int minCoins(int[] coins, int sum) {
    int[] dp = new int[sum + 1];
    Arrays.fill(dp, 1000000);          // «недостижимо»
    ⟦dp[0] = 0;||dp[0]=0⟧                         // база

    for (int s = 1; s <= sum; s++) {
        for (int c : coins) {
            if (⟦c <= s⟧) {
                dp[s] = Math.min(dp[s], ⟦dp[s - c] + 1⟧);
            }
        }
    }
    if (dp[sum] >= 1000000) return ⟦-1⟧;   // собрать нельзя
    return dp[sum];
}

Не забудьте импорт

import java.util.Arrays; — иначе Arrays.fill не скомпилируется.

Порядок циклов

Снаружи суммы, внутри монеты. Тогда dp[s − c] уже посчитано.

Проверка на −1

Если в ячейке осталось «недостижимо», собрать сумму нельзя.

Четыре пропуска. После проверки перенесите метод в свою программу и запустите на трёх тестах со слайда с условием.

Раздел 4 · Задача 3 · 3 балла

Задача 3: заявки на аудиторию

Условие

Даны два массива: start и end — время начала и конца заявок. Массивы уже отсортированы по времени окончания. Аудитория одна. Сколько заявок максимум можно принять?

static int maxActivities(int[] start, int[] end)

Ответ для проверки

start = {1, 3, 0, 5, 8, 5}
end   = {2, 4, 6, 7, 9, 9}
ответ → 4

Это жадная задача: таблица здесь не нужна.

Выбери максимум непересекающихся заявок кликами, потом посмотри жадное решение.

Раздел 4 · Задача 3 · практика

Заполни пропуски в maxActivities

// массивы уже отсортированы по времени окончания
static int maxActivities(int[] start, int[] end) {
    int count = 0;
    int lastEnd = 0;          // когда освободилась аудитория

    for (int i = 0; i < start.length; i++) {
        if (⟦start[i] >= lastEnd⟧) {   // заявка начинается после предыдущей
            count++;
            ⟦lastEnd = end[i];||lastEnd=end[i]⟧
        }
    }
    return count;
}

Вся жадность — в одной строке

Берём заявку, если она не мешает уже выбранным. И запоминаем новое время освобождения.

Почему >=, а не >

Заявка, которая начинается ровно в момент окончания предыдущей, помещается: одна закончилась в 4, вторая начинается в 4.

Сложность

O(n) — один проход. Если массивы не отсортированы, добавится сортировка: O(n log n).

Что будет, если забыть строку lastEnd = end[i];?

Раздел 4 · Задача 3 · разбор

Три способа испортить жадность

1. Сортировка по началу

Возьмём длинную заявку 0–6 первой и потеряем 1–4 и 5–7. Сортировать нужно по концу.

2. Сортировка по длительности

Короткая заявка посередине может разрезать интервал и помешать двум другим.

3. Условие с >

Заявка, начинающаяся ровно в момент освобождения, будет отброшена, и ответ окажется меньше.

Раздел 5 · Задача 4 · +2 балла

Задача со звёздочкой: сумма без соседей

Условие

Дан массив чисел. Выбрать числа с максимальной суммой так, чтобы не брать два соседних.

static int maxNonAdjacent(int[] a)

Три вопроса:

  • dp[i] — лучшая сумма на отрезке от начала до i.
  • База: dp[0] = a[0], dp[1] = max(a[0], a[1]).
  • Переход: для каждого числа решаем — берём его или пропускаем.

dp[i] = max(dp[i−1], dp[i−2] + a[i])

Разбор на примере {3, 2, 7, 10}

ia[i]Пропустить
dp[i−1]		Взять
dp[i−2] + a[i]		dp[i]
03—база3
12323
2733 + 7 = 1010
310103 + 10 = 1313

Ответ 13 — это числа 3 и 10. Соседей в выборе нет.

Чему равен ответ для массива {3, 2, 5, 10, 7}?

Раздел 5 · Задача 4 · практика

Код задачи со звёздочкой

static int maxNonAdjacent(int[] a) {
    if (a.length == 0) return 0;          // пустой массив
    if (a.length == 1) return a[0];       // одно число

    int[] dp = new int[a.length];
    dp[0] = a[0];
    dp[1] = Math.max(a[0], a[1]);

    for (int i = 2; i < a.length; i++) {
        dp[i] = Math.max(⟦dp[i - 1]⟧,          // пропускаем a[i]
                         ⟦dp[i - 2] + a[i]⟧);  // берём a[i]
    }
    return dp[a.length - 1];
}

Две базы

Формула смотрит на две ячейки назад, значит dp[0] и dp[1] нужно задать руками.

Почему тут < a.length

Здесь индексы — это позиции в массиве a, а не «размер задачи». Ответ лежит в последней ячейке.

Проверка

{3,2,7,10}   → 13
{3,2,5,10,7} → 15
{5}          → 5

Два пропуска: «пропускаем» и «берём». Эта задача даёт +2 балла, но только если три основные уже работают.

Вывод «ожидаем …» оставьте в коде — так и вам, и мне видно, что сходится.

Что чаще всего ломается

Без dp[0] вся таблица состоит из нулей.

Жадность вместо ДП

В задаче про монеты проходит только тест с обычными номиналами.

Шпаргалка на время КТ

Лестница

dp[0] = 1, dp[1] = 1
dp[i] = dp[i−1] + dp[i−2]

Монеты

dp[0] = 0, остальное «недостижимо»
dp[s] = min(dp[s−c]) + 1

Заявки (жадный)

Идём по отсортированным по концу заявкам:
если start[i] >= lastEnd — берём и обновляем lastEnd.

Сумма без соседей

dp[0] = a[0], dp[1] = max(a[0], a[1])
dp[i] = max(dp[i−1], dp[i−2] + a[i])
