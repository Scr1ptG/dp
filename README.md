# Алгоритмы и структуры данных — учебные материалы

Интерактивные презентации для пары и эталонные реализации на Java. Каждая презентация — один самостоятельный HTML-файл: скачал, открыл в браузере, листаешь стрелками. Ничего устанавливать не нужно.

Шрифты подгружаются с Google Fonts, поэтому без интернета они заменятся системными — на содержимое это не влияет.

## Презентации

| Файл | Тема | Что внутри |
|---|---|---|
| [01-sorting.html](01-sorting.html) | Сортировки | Что такое сортировка, сравнение и swap, пузырёк, слияние, быстрая, бинарный поиск |
| [02-recursion.html](02-recursion.html) | Рекурсия | Базовый случай, стек вызовов, факториал, Фибоначчи и мемоизация, Ханойские башни |
| [03-graphs.html](03-graphs.html) | Графы | Вершины и рёбра, матрица смежности, список смежности, что выбрать |
| [04-bst.html](04-bst.html) | Дерево поиска | Правило дерева, вставка, поиск, обход по порядку, задание КТ3 |
| [05-dp-greedy.html](05-dp-greedy.html) | ДП и жадные алгоритмы | Лестница, размен монет, задача о заявках (пара на 80 минут) |
| [06-kt5-practicum.html](06-kt5-practicum.html) | Практикум к КТ5 | Четыре задачи с разбором, сборкой кода и чек-листом тестов |
| [07-test-40.html](07-test-40.html) | Итоговый тест | 40 вопросов по всем темам, оценка и разбор ошибок |

В каждой презентации есть практика прямо на слайдах: анимации алгоритмов, пошаговые тренажёры, сборка кода из строк, пропуски в коде и мини-тесты с подсчётом баллов.

## Эталонные реализации

| Папка | Контрольная | Методы |
|---|---|---|
| [kt2-reference](kt2-reference) | КТ2 — сортировки | `mergeSort`, `merge`, `quickSort`, `partition`, `swap` |
| [kt5-reference](kt5-reference) | КТ5 — ДП и жадные | `ways`, `minCoins`, `maxActivities`, `maxNonAdjacent` |

Каждый файл содержит методы и набор тестов с печатью `OK` / `FAIL`, включая краевые случаи: пустой массив, один элемент, повторы, невозможный размен.

```bash
javac Main.java && java Main
```
