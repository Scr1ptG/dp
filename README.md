# Динамическое программирование и жадные алгоритмы

Материалы одной темы: лекция на пару и практикум к КТ5. Презентации — самостоятельные HTML-файлы: скачал, открыл в браузере, листаешь стрелками. Устанавливать ничего не нужно.

Шрифты подгружаются с Google Fonts, поэтому без интернета они заменятся системными — на содержимое это не влияет.

## Лекция

**[lecture-dp-greedy.html](lecture-dp-greedy.html)** — пара на 80 минут с хронометражем по разделам.

- Зачем нужно ДП: от мемоизации к таблице
- Задача про лестницу: интуиция, формула, код
- Размен монет: почему жадность ошибается и как считает таблица
- Жадные алгоритмы и задача о заявках
- Что выбирать, частые ошибки, мини-тест

Практика прямо на слайдах: пошаговое заполнение таблиц ДП, перебор способов подняться по лестнице, жадный размен монет, таймлайн заявок, пропуски в коде.

## КТ5

**[kt5-practicum.html](kt5-practicum.html)** — практикум: четыре задачи с разбором, тренажёрами, сборкой кода из строк и разбором чужих ошибок. Там же заготовка `Main.java`, чек-лист тестов и критерии оценки.

**[kt5-reference/Main.java](kt5-reference/Main.java)** — эталонное решение с 15 тестами, включая краевые случаи.

```bash
javac Main.java && java Main
```
