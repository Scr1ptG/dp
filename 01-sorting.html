Раздел 4 · Пузырёк

Пузырёк: от слов к коду

  • Повторить проходы n − 1 разfor (int i ...)
  • Пройти по соседям, кроме готового хвостаfor (int j ...)
  • Если левый больше правогоif (a[j] > a[j + 1])

Почему медленно

Для 1000 чисел — около 500 000 сравнений. Каждый сравнивается почти с каждым: O(n²).

static void bubbleSort(int[] a) {
    int n = a.length;
    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - 1 - i; j++) {
            if (⟦a[j] > a[j + 1]||a[j+1] < a[j]⟧) {
                int tmp = a[j];
                a[j] = ⟦a[j + 1]⟧;
                a[j + 1] = tmp;
            }
        }
    }
}

Раздел 5 · Сортировка слиянием

Разделяй и властвуй

Преподавателю нужно разложить 8 работ по фамилиям. Одному долго. Он хитрит:

1. Делим

Отдаёт половину стопки одному помощнику, половину — другому. Те тоже делят пополам… пока у каждого не останется по одной работе.

2. Сливаем

Соседи объединяют свои стопки по порядку. Потом ещё раз, пока не соберётся одна стопка.

Живой пример: 8 студентов с числами. Делите группу пополам, пока каждый не встанет один. Потом соединяйтесь парами — меньший встаёт левее.

Почему группа из одного элемента уже отсортирована?

Раздел 5 · Слияние · шаг 1

Делим, пока в группе не останется один

Каждую группу режем пополам. Сравнивать пока ничего не нужно — только делим.

Если элементов нечётное число, левая половина на один больше: [5, 2, 8, 1, 9] → [5, 2, 8] и [1, 9].

Жми «Дальше» — дерево растёт вниз.

Раздел 5 · Слияние · шаг 2

Сливаем две группы по порядку

Обе группы уже отсортированы. Поэтому смотрим только на их первые элементы.

  • Сравниваем первые элементы двух групп.
  • Меньший забираем в результат.
  • Одна группа кончилась — остаток другой переносим целиком.

Как два ряда по росту сливаются в один: каждый раз вперёд выходит самый низкий из двух первых.

Кликай по меньшей из двух первых карточек (с синей рамкой).

Раздел 5 · Собираем алгоритм · шаг 1

Сначала — словами

Собери из строк план двух функций. mergeSort — делит и вызывает сам себя. merge — сливает две группы.

Раздел 5 · Собираем алгоритм · шаг 2

mergeSort на Java

  • если 0 или 1 элемент — выйтиif (left >= right) return;
  • найти серединуmid = (left + right) / 2
  • левая половинаleft … mid
  • правая половинаmid + 1 … right
static void mergeSort(int[] a, int left, int right) {
    if (⟦left >= right||left == right⟧) return;
    int mid = ⟦(left + right) / 2||left + (right - left) / 2⟧;
    mergeSort(a, left, mid);
    mergeSort(a, ⟦mid + 1⟧, right);
    merge(a, left, mid, right);
}

Заполни три пропуска в коде. Справа нажимай «Следующий вызов» — увидишь, в каком порядке вызывается функция: сначала спуск до одиночек, потом merge.

Раздел 5 · Частые ошибки

Найди ошибку в merge

static void merge(int[] a, int left, int mid, int right) {
    int[] tmp = new int[right - left + 1];
    int i = left, j = mid + 1, k = 0;
    while (i <= mid && j <= right) {
        if (a[i] <= a[j]) { tmp[k] = a[i]; i++; }
        else              { tmp[k] = a[j]; j++; }
        k++;
    }
    for (int t = 0; t < tmp.length; t++) a[left + t] = tmp[t];
}

Ошибки, которые делают чаще всего

  • Забыли перенести остатки.
  • j = mid вместо mid + 1.
  • a[t] = tmp[t] вместо a[left + t].

Раздел 6 · Быстрая сортировка

Опорный: меньше — налево, больше — направо

Учитель выбирает одного студента — опорного (pivot). Кто ниже него — встаёт слева, кто выше — справа.

Опорный сразу оказывается точно на своём месте. Слева и справа ещё беспорядок — но это уже две маленькие задачи.

Живой пример: опорный — последний в ряду. Остальные по очереди решают: налево или направо.

Раздел 6 · Быстрая

Как разбить прямо в массиве

  • pivot — последний элемент группы.
  • i — где кончается зона «меньше» (светло-зелёная).
  • j идёт по группе. Нашли число меньше pivot — сдвигаем i и меняем a[i] и a[j].
  • В конце ставим pivot сразу за зоной «меньше».
pivot сравниваем зона «меньше» на своём месте

Порядок внутри зон может отличаться от дерева на прошлом слайде — это нормально, главное: слева меньше, справа больше.

Раздел 6 · Быстрая · практика

Будь компьютером: разбиение

На каждом шаге сравни a[j] с pivot и выбери действие.

Раздел 6 · Собираем алгоритм · шаг 1

Сначала — словами

quickSort — разбивает и вызывает себя для левой и правой части. partition — само разбиение.

Раздел 6 · Собираем алгоритм · шаг 2

partition на Java: собери из строк

Подсказка: план

pivot → i → цикл по j → если меньше: i++ и swap → pivot на i + 1 → вернуть

swap уже знаешь

static void swap(int[] a, int i, int j) {
    int tmp = a[i];
    a[i] = a[j];
    a[j] = tmp;
}

Раздел 6 · Собираем алгоритм · шаг 3

quickSort на Java и частые ошибки

static void quickSort(int[] a, int low, int high) {
    if (⟦low >= high||low == high⟧) return;
    int p = partition(a, low, high);
    quickSort(a, low, ⟦p - 1⟧);
    quickSort(a, ⟦p + 1⟧, high);
}
  • quickSort(a, low, p) — pivot снова попадает в группу, рекурсия не кончается.
  • j <= high в partition — сравниваем pivot сам с собой.
  • quickSort(a, 0, a.length) — выход за границу массива.

Студент написал quickSort(a, low, p); вместо p - 1. Что может случиться?

Раздел 7 · Бинарный поиск

То же самое в отсортированном массиве

  • lo и hi — границы, где число ещё может быть.
  • mid — середина. Сравниваем a[mid] с искомым.
  • Меньше — ищем справа, больше — слева.

Работает только на отсортированном массиве.

Раздел 7 · Бинарный поиск

Бинарный поиск на Java

static int binarySearch(int[] a, int target) {
    int lo = 0, hi = a.length - 1;
    while (⟦lo <= hi⟧) {
        int mid = (lo + hi) / 2;
        if (a[mid] == target) return mid;
        if (a[mid] < target) lo = ⟦mid + 1⟧;
        else                 hi = ⟦mid - 1⟧;
    }
    return -1;   // не нашли
}

Где пригодится

Поиск в словаре и списке контактов, Arrays.binarySearch в Java, поиск в базах данных.

Ловушка

lo < hi вместо <= — последний оставшийся элемент не проверится.
