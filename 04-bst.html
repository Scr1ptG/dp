Раздел 1 · Зачем дерево

Проблема: список ищет долго

Связный список

Вставить легко, а найти число — пройти по всем узлам подряд: O(n).

Отсортированный массив

Искать быстро, O(log n), но при вставке в середину приходится сдвигать половину массива.

Дерево поиска

И поиск, и вставка — O(log n): на каждом шаге отбрасываем половину.

Каждый шаг вниз по дереву выбрасывает половину оставшихся чисел — ровно как в игре «угадай число».

Раздел 1 · Зачем дерево

Как устроено дерево

Корень (root)

Самый верхний узел. С него начинается любой поиск.

Потомки

У каждого узла максимум двое детей: левый и правый. Отсюда «бинарное».

Лист

Узел без детей — дальше идти некуда.

Высота

Сколько уровней в дереве. Это и есть число шагов в худшем случае.

Раздел 2 · Правило дерева

Слева меньше, справа больше

Для каждого узла: всё, что в левом поддереве, меньше его. Всё, что в правом, — больше.

Правило выполняется не только для корня, но и для любого узла внутри дерева.

Из-за этого правила дерево и называется деревом ПОИСКА: оно само подсказывает, куда идти.

Проверь правило на узле 30

Слева от 30 стоит 20 (меньше), справа 40 (больше). И оба меньше 50 — значит, всё поддерево стоит слева от корня.

Раздел 2 · Вставка

Куда встанет новое число

Сравниваем новое число с узлом и идём налево или направо, пока не упрёмся в пустое место. Реши сам, куда идти.

Раздел 2 · Вставка

Порядок вставки решает всё

Числа вперемешку: 50, 30, 70, 20, 40

Дерево раскидистое, высота 3. Поиск — 3 сравнения.

Числа по порядку: 20, 30, 40, 50, 70

Получилась «палка», высота 5. Поиск превращается в обычный перебор — O(n).

Поэтому в реальных программах используют самобалансирующиеся деревья (AVL, красно-чёрное). Нам их знать пока не нужно — просто не вставляйте числа строго по возрастанию.

Раздел 2 · Поиск

Поиск: по одному сравнению на уровень

  • Сравниваем искомое число с узлом.
  • Равно — нашли.
  • Меньше — идём налево, больше — направо.
  • Уткнулись в пустоту — числа в дереве нет.

Впиши своё число и нажимай «Шаг» — путь подсветится.

Раздел 3 · Обход дерева

Дерево умеет выдавать числа по порядку

Обход in-order (по возрастанию): сначала всё левое поддерево, потом сам узел, потом правое.

inOrder(узел):
    если узла нет — выйти
    inOrder(левый)
    напечатать узел
    inOrder(правый)

Это снова рекурсия: три строчки — и числа выходят отсортированными.

Раздел 4 · Код на Java

Узел дерева — это класс Node

static class Node {
    int value;      // число в узле
    Node left;      // левый потомок (меньше)
    Node right;     // правый потомок (больше)

    Node(int value) {
        this.value = value;
    }
}

Знакомая конструкция: в КТ1 узел списка хранил prev и next. Здесь вместо соседей — двое детей.

Пустое дерево

Это просто Node root = null; — ни одного узла.

Пустое место

Если node.left == null, то слева никого нет. Именно туда и встанет новое число.

left и right по умолчанию равны null — Java заполняет ссылки нулями сама.

Раздел 4 · Код на Java

Вставка: рекурсия в три строки

static Node insert(Node node, int value) {
    if (⟦node == null⟧) {
        return new Node(value);              // дошли до пустого места
    }
    if (⟦value < node.value⟧) {
        node.left = insert(node.left, value);    // идём налево
    } else if (value > node.value) {
        node.right = ⟦insert(node.right, value);||insert(node.right,value)⟧;
    }
    return node;                             // равные не добавляем
}

// в main:  root = insert(root, 50);

Базовый случай

node == null — место найдено, создаём узел и возвращаем его.

Зачем присваивание

node.left = insert(node.left, value): вложенный вызов возвращает поддерево, и мы прикрепляем его обратно. Без присваивания дерево не вырастет.

Зачем return node

Узел возвращает сам себя, чтобы родитель мог снова к нему привязаться.

Студент написал просто insert(node.left, value); без node.left =. Что получится?

Раздел 4 · Код на Java

Поиск и обход

static boolean contains(Node node, int value) {
    if (node == null) return false;       // дошли до пустоты
    if (⟦value == node.value⟧) return true;
    if (value < node.value) {
        return ⟦contains(node.left, value);||contains(node.left,value)⟧
    }
    return contains(node.right, value);
}

Та же развилка, что при вставке: меньше — налево, больше — направо.

static void inOrder(Node node) {
    if (node == null) return;
    inOrder(node.left);                   // сначала всё меньшее
    System.out.print(node.value + " ");   // потом сам узел
    ⟦inOrder(node.right);||inOrder(node.right)⟧                 // потом всё большее
}

static int min(Node node) {
    while (node.left != null) {
        node = node.left;                 // самый левый узел
    }
    return node.value;
}

static int height(Node node) {
    if (node == null) return 0;
    return 1 + Math.max(height(node.left),
                        height(node.right));
}

Раздел 4 · Практика

Собери метод insert

Кликай строки в правильном порядке. Помни: сначала базовый случай, потом развилка, в конце возврат узла.

Раздел 4 · Частые ошибки

Четыре ошибки, которые встретятся почти у всех

1. Потерянное присваивание

insert(node.left, value); вместо node.left = insert(node.left, value); — дерево не растёт.

2. Забыли про корень

В main нужно root = insert(root, v);. Без присваивания дерево останется пустым.

3. Нет проверки на null

Обращение к node.value, когда node == null, даёт NullPointerException.

4. Перепутаны стороны

Меньшие ушли направо — in-order напечатает числа по убыванию. Это сразу видно при проверке.

Программа печатает 80 70 60 50 40 30 20. Что случилось?

Раздел 5 · КТ3

Заготовка и ожидаемый вывод

public class Main {

    static class Node {
        int value;
        Node left, right;
        Node(int value) { this.value = value; }
    }

    // сюда: insert, contains, inOrder, min, height

    public static void main(String[] args) {
        Node root = null;
        int[] data = {50, 30, 70, 20, 40, 60, 80};
        for (int v : data) {
            root = insert(root, v);      // корень обязательно перезаписываем
        }

        System.out.print("По порядку: ");
        inOrder(root);
        System.out.println();

        System.out.println("Есть 40? " + contains(root, 40));
        System.out.println("Есть 45? " + contains(root, 45));
        System.out.println("Минимум: " + min(root));
        System.out.println("Высота: " + height(root));
    }
}

Должно вывести

По порядку: 20 30 40 50 60 70 80
Есть 40? true
Есть 45? false
Минимум: 20
Высота: 3

Если первая строка вышла не по возрастанию — ищи ошибку в insert, а не в inOrder.
